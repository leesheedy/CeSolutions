# CES: good energy, close to home
Animation mode: non-animated

Existing-site refinement, 20 September 2026. The user asked to simplify the site, remove unnecessary elements and substantially improve the savings section and 3D model. Editorial layout with restrained motion is the implementation of that direction, rather than restarting the older cinematic-film concept.

Audience: homeowners considering solar or storage in Albury-Wodonga.
Purpose: understand the offer, inspect real installation work and enquire with confidence.
Brand: retain the CES logo and blue; add white, mineral green and deep teal surfaces.
Type: existing self-hosted Bricolage Grotesque, clearer hierarchy and generous line spacing.
Photography: existing real CES images only. No generated installation claims.
Hero: benefit-led split layout with a real rooftop installation and a primary quote link.
Sections: hero and proof strip; solar/battery services; interactive savings and home illustration; selected work; local team; one review; four FAQs; short enquiry.
Savings: user chooses a quarterly bill and a 25/50/75% scenario. Annual reduction is arithmetic only. No generated forecast, system sizing, payback or live output claims.
Home illustration: projected 3D architectural geometry, rooftop array and external battery. Keyboard-accessible rotation plus explicit day/evening controls. No perpetual animation, clock-based darkness, external model runtime or per-frame React state.
Motion: one modest hero settle, button feedback and short transitions. Reduced-motion users get instant changes. All content stays visible without scroll-triggered reveals.
Enquiry: one page, required name/phone/suburb, optional email/message, simple service selector. No upload or checklist dependency. Email delivery is explicitly out of scope.
SEO: retain routes, titles, canonical targets, robots and sitemap. Remove obsolete FAQ structured data from the homepage because its questions changed.
Hosting: public Netlify site remains the deliverable. Higgsfield project checkout failed; its cloud sandbox was used to author the current GitHub-backed site. Do not redeploy an older Higgsfield revision.
Community gallery: do not list.
